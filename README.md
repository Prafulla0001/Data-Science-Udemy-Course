# Data Science Udemy Course

This repository is a hands-on Python learning journey covering foundational programming, object-oriented programming, data analysis, and practical data science concepts. It includes a large collection of Jupyter notebooks, assignments, and example scripts created as part of a Udemy-style data science course.

## Overview

The notebooks in this repo progressively cover:

- Python basics: variables, operators, data types, loops, and functions
- Collections: lists, tuples, sets, dictionaries
- Advanced Python: lambda functions, map/filter, generators, iterators, decorators
- Object-oriented programming: classes, objects, inheritance, polymorphism, encapsulation, abstraction, operator overloading, magic methods
- Exception handling and debugging
- File handling and package/module usage
- NumPy and Pandas-based data analysis
- Custom package examples and practical coding exercises

## Repository Structure

- `Abstraction.ipynb` — abstraction concepts
- `ClassesAndObjects.ipynb` — OOP fundamentals
- `Dictionaries.ipynb` — dictionary operations and examples
- `Functions.ipynb` — functions and reusable logic
- `Exception_Handling.ipynb` — exception handling examples
- `Assignment 1.ipynb` to `Assignment 16.ipynb` — course assignments covering various Python topics
- `Data Analysis With Python/` — notebooks and files related to analysis workflows
- `File Handling/` — examples for reading, writing, and processing files
- `Function Practice Questions/` — practice exercises for functions
- `Custom_Package/` — custom Python package examples
- `requirements.txt` — Python dependency list
- `test.py` and other utility scripts — supporting examples

## Tech Stack

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Standard Python libraries

## Getting Started

### Prerequisites

Make sure you have Python 3 installed on your machine.

### Install dependencies

```bash
pip install -r requirements.txt
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Then open any `.ipynb` file in the browser and run the cells.

## Recommended Learning Path

1. Start with the basic notebooks such as `Variables.ipynb`, `Operators.ipynb`, `Datatypes.ipynb`, and `Looping.ipynb`
2. Move on to collections and functions
3. Study OOP notebooks and assignments
4. Practice with file handling and package examples
5. Explore NumPy and Pandas-related notebooks for data analysis
